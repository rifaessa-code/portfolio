# 📊 Power BI Dashboard — TPT & SDM Provinsi Sumatera Barat

## 📌 Overview
This project presents an interactive Power BI dashboard designed to monitor **Tingkat Pengangguran Terbuka (TPT)** and **Human Resources (SDM)** indicators in **West Sumatra Province**.  
The dashboard aims to support data-driven insights related to labor market conditions and workforce characteristics.

## 🎯 Objectives
- Monitor trends of TPT across time
- Analyze labor force indicators related to SDM
- Support descriptive analysis for employment conditions at the provincial level

## 📈 Key Indicators
- Tingkat Pengangguran Terbuka (TPT)
- Tingkat Partisipasi Angkatan Kerja (TPAK)
- Employment structure indicators
- Supporting human resource variables

## 🗂 Data Source
The data used in this dashboard are secondary data obtained from official statistical sources and processed for analytical and visualization purposes.

## 🛠 Tools
- Microsoft Power BI
- Microsoft Excel

## 📊 Dashboard Features
- Interactive filters (year / category)
- Trend visualization
- Comparative analysis between indicators
- Clean and user-friendly layout
