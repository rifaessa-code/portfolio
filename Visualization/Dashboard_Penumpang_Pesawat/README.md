# 🛫 Data Visualization — Passenger Flight Data (2019–2024)  
Created using Microsoft Power BI

---

## 📊 Overview
This project presents an interactive **data visualization dashboard** built with **Microsoft Power BI**, focusing on passenger flight data from four major airports in Indonesia:

- **KNO** — Kualanamu  
- **CGK** — Soekarno-Hatta  
- **SUB** — Juanda  
- **DPS** — I Gusti Ngurah Rai  

The dataset covers the years **2019 to 2024**, allowing analysis of passenger trends before, during, and after the pandemic period.

---

## 🗂 Dataset
- **Source**: Passenger flight data (2019–2024)  
- **Content Includes**:
  - Total passenger counts per year/month  
  - Data by airport (KNO, CGK, SUB, DPS)  
  - Possible segmentation (domestic vs international)  

---

## 🖥 Dashboard Components

### **1. Total Passenger Trends (2019–2024)**
A line or area chart showing overall passenger movement across the selected years.

### **2. Passenger Comparison by Airport**
A comparative visualization (bar chart / column chart) displaying passenger volumes from each airport.

### **3. Interactive Filters**
The dashboard includes slicers/filters such as:
- Year  
- Airport
